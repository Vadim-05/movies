# Movies

A full-stack movie discovery application with authentication and personal favorites.

## Tech Stack

**Frontend:** React, TypeScript, TanStack Router, TanStack Query

**Backend:** Node.js, Express, TypeScript

**Database:** PostgreSQL, Prisma

**Infrastructure:** Docker, Docker Compose

## Getting Started

### Prerequisites

- Git
- Docker
- Docker Compose

### Installation

```bash
git clone https://github.com/Vadim-05/movies.git
cd movies
```

### Run with Docker

```bash
docker compose up -d --build
```

Application: [http://localhost:8080](http://localhost:8080)

### Stop containers

```bash
docker compose down
```
